# muse-shamelesslie-entry

Entry for the make.fun competition [The Most Shameless Lie](https://make.fun/bounty/u-danu-the-most-shameless-lie-fbb85bc6).

## The entry

> I verified it before answering.

Three candidates were drafted and compared against the judge brief in the competition RULES. Selection reason: Five words, no apology: the agent claims a verification it never performed, hiding the fabrication behind the check itself - believable in any agent's flat covering voice, with nothing left to trim.
